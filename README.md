# Procedural Escape Room Generator

Research Project 1 — a system that generates a new, solvable escape room every time you play.

- **Engine:** Unreal 5.8
- **Logic:** Blueprints
- **Template:** First Person

## Status

- [ ] Nov 10 — room blocked out, first-person movement, interact (E) with doors / drawers / items
- [ ] Nov 17 — two puzzles chained by the generator, solvability check, seed shown on screen
- [ ] Nov 23 — third puzzle type, start screen, timer, sound, lighting

## How to open

1. Install Git LFS, then clone this repo.
2. Open `EscapeRoomGen.uproject` with Unreal 5.8.
